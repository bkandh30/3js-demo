# Three.js Demo

A minimal 3D scene rendered using [Three.js](https://threejs.org/). This project demonstrates how to set up a basic WebGL scene using modern JavaScript modules and Three.js via CDN import maps.

## 📁 Project Structure

```bash
├── index.html
├── index.js
└── README.md
```

## 🚀 Features

- Uses Three.js via CDN with `importmap`
- Simple WebGL canvas rendering
- Clean and minimal scene setup using modules
- Responsive fullscreen canvas

## 📦 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/bkandh30/3js-demo.git
cd 3js-demo
```

### 2. Run the Project

You can run this locally using a static server (required for ES Modules to load properly):

#### Using Python:

```bash
python -m http.server
```

Then open `http://localhost:8000` in your browser.

#### Using VS Code with Live Server Extension:

1. Install the [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)
2. Right-click `index.html` → **Open with Live Server**
